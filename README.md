# Meine Vokabeln

Kleine Vokabel-Lern-App für Kinder (Englisch ↔ Deutsch).

- Wörter selbst eintragen (mit Beispielsatz und Unit)
- 🔊 Aussprache über die Vorlesefunktion des Geräts
- Üben mit Karteikarten (Lernfächer: nicht gewusste Wörter kommen öfter dran)
- Sterne und „heute geübt“
- Läuft offline, alle Daten bleiben auf dem Gerät
- 💾 Sicherung als JSON-Datei speichern und laden

Auf dem iPad: In Safari öffnen → Teilen → „Zum Home-Bildschirm“.
